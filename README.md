# Million Technology — Premium Website Template v2

A fresh, photo-led multi-page HTML/CSS/Vanilla JavaScript website for Million Technology.

## What's different in this version
- New premium editorial/technology template rather than the previous layout.
- Institute photos are used throughout Home, About, Courses, Course Details, Internships, Placements, Testimonials, Blogs and Contact.
- There is no gallery-only approach.
- All photos in `assets/images/` are dummy images and can be replaced with your real institute photos.
- Exact supplied Million Technology logos are included in `assets/logo/`.
- Responsive mobile navigation.
- Course search/filtering.
- Dynamic course detail content through query parameters.
- FAQ and curriculum accordions.
- Scroll reveal animations and animated counters.
- Demo forms are front-end only and show a message until connected to your backend/WhatsApp/email service.

## Replace dummy photos
Replace files inside:

`assets/images/`

Recommended mapping:
- `hero-learning.jpg` → best institute/classroom/hero photo
- `classroom-1.jpg`, `classroom-2.jpg`, `classroom-3.jpg` → classroom/training photos
- `students-1.jpg`, `students-2.jpg`, `students-3.jpg` → student activity photos
- `internship.jpg` → internship/project photo
- `lab-1.jpg`, `lab-2.jpg`, `lab-3.jpg` → lab/technology photos
- `placement-1.jpg` … `placement-5.jpg` → student/placement photos
- `blog-1.jpg` … `blog-3.jpg` → blog/event photos

Keep the same filenames if you want to replace images without changing the HTML.

## Logo
The supplied logo is already included. Do not change its colors or proportions.

## Run locally
Open `index.html` in a browser. For the smoothest experience, use VS Code Live Server.
